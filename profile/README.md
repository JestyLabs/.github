<h1 align="center">Jesty</h1>

<p align="center">
  <strong>Open-source tools for Android gaming handhelds.</strong>
</p>

Jesty is a collection of small community tools built to solve hardware and software quirks on Android gaming handhelds.

## Projects

### 🎮 Jesty Thor Fix

True lower-display power-off for the AYN Thor.

- Real bottom-display scanout disable
- Automatic wake repair
- Live display / CPU telemetry
- Hardware-verified behavior

👉 [Jesty Thor Fix](https://github.com/JestyLabs/Jesty-Thor-Fix)

---

### 🔋 Jesty RP Charging Separation

Native charging separation for Retroid Pocket 5 and Retroid Pocket Flip 2.

- Uses Retroid's native charging controls
- Live battery / USB telemetry
- Automatic safety fallback
- No Magisk setup required

👉 [Jesty RP Charging Separation](https://github.com/JestyLabs/Jesty-RP-Charging-Separation)

---
